# Nettside (statisk forhåndsvisning)

Statisk nettside (HTML/CSS/JS). Deployes automatisk til GitHub Pages via GitHub Actions ved push til `main`.

- Nettside: `https://<brukernavn>.github.io/<repo-navn>/`
- Kontaktskjema (`php/send.php`) krever PHP — fungerer ikke på GitHub Pages (kun statisk hosting). På shared hosting fungerer den som normalt.
